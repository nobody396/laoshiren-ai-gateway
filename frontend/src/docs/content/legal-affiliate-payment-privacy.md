# 合伙人收款资料隐私告知

发布日期：2026-07-30

版本：affiliate-payment-profile-privacy-v1

本告知用于说明老实人AI在合伙人资料审核和佣金打款过程中，如何处理你的支付宝收款资料。支付宝账号、收款码等可能属于敏感个人信息。提交前，请完整阅读本告知，并通过页面复选框作出单独同意。

## 1. 我们处理哪些信息

你主动提交或在相关操作中产生的信息包括：

- 支付宝实名、支付宝账号、联系电话；
- 支付宝收款码图片、原始文件名和文件大小；
- 你填写的打款备注；
- 本告知的版本、由服务器记录的同意时间；
- 资料审核状态、审核意见、审核人员和审核时间；
- 提现申请中的收款资料快照、处理状态、打款参考号；
- 为安全审计记录的收款码查看人、查看场景和查看时间。

请不要在备注或收款码图片中提交与收款无关的身份证号码、银行卡号、住址或其他个人信息。

## 2. 处理目的和必要性

我们仅在以下必要范围内处理这些信息：

1. 确认合伙人收款身份和资料完整性；
2. 按你的提现申请向指定支付宝账户打款；
3. 联系你核对打款失败、资料异常或争议；
4. 防止重复身份、虚假交易、自邀互刷、盗用收款资料等风险；
5. 保存结算、申诉、安全审计及适用法律要求的必要记录。

支付宝实名、账号和收款码是完成支付宝打款所必需的信息。你可以拒绝提供或撤回同意，这不会影响普通账号继续使用平台基础服务，但你将无法完成收款资料审核、申请支付宝提现或继续使用依赖这些资料的合伙人收款能力。

## 3. 谁可以访问

只有因审核、打款、客服、风控、安全审计或争议处理确有需要的授权人员可以访问相关资料。我们可能在完成打款或依法履责所必需的范围内，向支付宝等支付服务提供方、基础设施服务方、专业顾问或有权机关提供必要信息。

除非取得你的另行同意或法律另有规定，我们不会将这些资料用于广告画像、公开展示或与合伙人收款无关的用途，也不会出售这些资料。

## 4. 保存期限

我们只在实现上述目的所需的期限内保存相关资料：

- 合伙人关系存续、存在可结算佣金、提现处理中或争议未处理完毕期间持续保存；
- 关系结束且最后一笔打款、退款或争议完成后，为结算核对、安全审计和维权需要通常保存不超过 3 年；
- 法律法规、监管要求或未决争议要求更长保存期限的，按相应期限保存。

保存期限届满后，我们会删除或匿名化不再需要的信息；提现记录中为证明已完成交易所必需的最小信息可能继续依法保存。

## 5. 安全措施

我们采取访问权限控制、服务端同意版本和时间记录、收款码文件隔离、文件类型与尺寸校验、图片重新编码去除附加信息、查看审计和提现快照等措施，降低未经授权访问、篡改、丢失或滥用风险。

互联网服务无法保证绝对安全。如发生可能影响你权益的个人信息安全事件，我们会按适用要求采取补救措施并进行通知。

## 6. 你的权利

你可以通过官网客服申请：

- 查询、复制、更正或补充你的收款资料；
- 删除依法不再需要的资料；
- 解释本告知和具体处理规则；
- 撤回对后续处理的同意；
- 注销相关能力或提出投诉。

撤回同意不影响撤回前基于你的同意已经完成的处理。由于支付宝打款必须使用相应资料，撤回后我们会停止新的收款资料审核和提现；已经提交的提现、争议处理或依法必须保存的记录不受影响。

## 7. 告知更新与联系方式

如果处理目的、信息种类、使用方式或保存期限发生重要变化，我们会更新本告知，并在再次提交资料前重新取得必要同意。页面显示的版本与服务器记录的同意版本不一致时，需要重新阅读并同意。

如需行使权利、撤回同意、举报资料被冒用或咨询本告知，请通过老实人AI官网“客服”入口联系我们。

本告知是《服务条款》和《联盟计划规则》的补充。其他未尽事项以相关规则和适用法律为准。
