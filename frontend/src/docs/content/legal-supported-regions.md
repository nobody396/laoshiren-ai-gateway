# 支持的国家和地区

生效日期：2026-05-29

本页面说明老实人AI服务的地区可用性要求。地区可用性会受到适用法律法规、制裁和出口管制、支付渠道、上游模型服务商政策、网络质量、账号地区、业务用途和风控规则共同影响。

## 1. 中国大陆地区不支持

老实人AI不面向中国大陆地区用户提供服务。你继续访问或使用本服务，即声明并保证：

- 你当前不位于中国大陆地区。
- 你的账号注册、充值、API 调用、客户端配置和下游使用不发生在中国大陆地区。
- 你不会将本服务能力转售、分发、嵌入或提供给中国大陆地区用户或主要面向中国大陆地区的业务。
- 你不会通过 VPN、代理、虚拟定位、代注册、代付、共享账号、共享 API Key 或其他方式规避地区限制。

如果你位于中国大陆地区，或你的使用场景无法满足以上声明，请不要注册、充值、创建 API Key 或继续使用本服务。

## 2. 支持地区的判断方式

除中国大陆地区外，某个国家或地区是否可使用本服务，还需要同时满足以下条件：

- 当地法律法规允许你访问和使用相关 AI API、模型服务、支付服务和云服务。
- 你的使用不违反制裁、禁运、出口管制、反洗钱、数据跨境、隐私保护、行业许可或其他强制要求。
- 实际上游模型服务商允许相关地区、账号、付款方式、IP、组织或业务类型访问。
- 你和你的终端用户符合年龄、身份、企业资质、行业资质、内容合规和安全要求。
- 你没有通过自动化、代理池、异常 IP、盗刷、欺诈或其他方式触发平台和上游风控。

即使你所在地区通常可访问本服务，特定模型、账号池、支付渠道、价格、并发、功能或上游资源仍可能因服务商政策和实时可用性发生变化。

## 3. 明确不支持的地区和对象

以下地区、对象或场景不支持使用本服务：

- 中国大陆地区。
- 受适用制裁、禁运、出口管制或类似限制的国家、地区、个人、组织或实体。
- 上游模型服务商、支付机构、云服务商或其他第三方明确禁止或限制的地区、账号、付款方式、IP、业务或终端用户。
- 试图规避地区限制、身份限制、付款限制、行业许可、年龄限制或上游服务条款的使用。
- 主要用于向不符合条件的终端用户转售、分发、代理或提供访问的业务。

我们可以基于 IP、设备、支付、账号、请求来源、用量模式、上游反馈、客服沟通、订单信息或其他合理信号判断地区和合规风险。

## 4. 用户责任

你应自行确认你所在地、业务所在地、付款所在地、服务器所在地、终端用户所在地和数据处理所在地均符合相关要求。你应对地区误判、代理误用、付款风险、下游转售、终端用户违规、上游封禁、订单取消、余额冻结和服务终止承担责任。

如果你的业务涉及跨境团队、企业采购、多人共享、代理分发、客户端集成、终端用户访问或高风险行业，你应建立地区准入、身份校验、内容合规、日志审计和异常处置机制。

## 5. 地区变化

支持地区和限制地区可能随法律法规、监管要求、上游政策、支付渠道、网络环境、账号资源和风控要求变化而调整。我们可以在必要时临时或长期限制特定地区、IP、账号、模型、支付方式、企业主体或业务场景。

你在地区要求更新后继续使用本服务，即视为接受更新后的地区要求；如你不再符合要求，应立即停止使用本服务。
