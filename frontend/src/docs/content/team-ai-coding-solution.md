# 团队 AI 编码工具接入方案

很多团队会同时使用 Claude Code、Codex、Cursor、OpenAI 兼容客户端和其他 AI 编程工具。真正的问题不是“用哪个工具”，而是如何统一配置、统一管理、统一排错和统一看成本。

老实人AI可以作为团队 AI 编码工具的 API 接入层，让团队用一套规则管理多个工具。

## 适用场景

- 团队已经有人在用 Claude Code 或 Codex。
- 负责人希望看到 AI 编码工具的成本和调用记录。
- 企业需要统一 API Key，而不是成员自己管理。
- 客服、运维或技术负责人需要统一排查错误。
- 采购需要发票、合同和服务说明。

## 推荐架构

```text
团队成员 / AI 编码工具
        ↓
Claude Code / Codex / OpenAI 兼容客户端
        ↓
老实人AI API 入口
        ↓
分组、模型、用量、成本、调用记录
```

## 落地动作

1. 列出团队正在使用或计划使用的 AI 编码工具。
2. 选择核心工具先跑通，例如 Claude Code 和 Codex。
3. 给不同项目创建独立 API Key。
4. 建立分组说明，明确可用模型和费用边界。
5. 把配置方式写成内部 SOP。
6. 让成员遇到问题先按错误码排查。

## 常见错误

**错误一：所有成员共用同一个 Key。**  
这会让权限、费用和异常调用都无法归因。

**错误二：只培训安装，不培训排错。**  
团队推广 AI 编码工具时，401、429、503 的排查路径必须写清楚。

**错误三：只看工具体验，不看成本记录。**  
AI 编码工具要进入团队流程，必须能被负责人复盘。

## 企业咨询前需要确认

- 团队人数。
- 使用哪些 AI 编码工具。
- 是否需要发票和合同。
- 是否需要按项目拆分 Key。
- 是否有数据、代码、日志方面的内部安全要求。
