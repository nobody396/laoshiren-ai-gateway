# 模型目录

模型目录由实时接口生成。同一个模型可能由多个分组提供，请根据预算选择对应分组。

## 模型卡片怎么读

每张模型卡按下面的顺序展示：

1. 模型 ID；
2. 上下文、最大输出与模型原生输入；
3. 可以调用该模型的分组与倍率；
4. 已完成实测的协议；
5. 完成真实 Agent 闭环后可以直接使用的客户端。

点亮的文本、图片或视频表示模型 API 原生支持；灰色表示不支持。客户端抽帧或使用本地工具处理，不算原生支持。

协议相同只是候选条件。工具还可能依赖模型元数据、工具调用结构、流式事件格式或原生服务端工具，因此必须以卡片中的客户端实测结果为准。

创建或切换 Key 后，以该 Key 的 [`GET /v1/models`](api-models) 实时返回值为准，不要手写或猜测模型 ID。
