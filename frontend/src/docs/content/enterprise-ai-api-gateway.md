# 企业 AI API 网关方案

老实人AI可以作为企业团队的 AI API 网关和多模型统一接入层，帮助团队把 Claude Code、Codex、ChatGPT、Gemini 等编码模型接入统一入口。

## 适合哪些团队

- 团队里多人使用 Claude Code、Codex 或 OpenAI 兼容工具。
- 希望统一管理 API Key，而不是每个人各配各的。
- 希望看到项目、人员、模型和成本的调用记录。
- 希望把常见配置问题、报错排查和售后支持标准化。
- 需要发票、合同、对接说明和企业采购沟通。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 多模型统一接入 | 用统一入口接入 Claude Code、Codex、ChatGPT、Gemini 等工具场景。 |
| API Key 管理 | 为不同团队、项目或工具创建独立 Key。 |
| 分组管理 | 通过分组控制模型、协议、倍率、限制和路由。 |
| 用量统计 | 查看调用记录、模型、成本和错误。 |
| 成本控制 | 按项目或工具拆分 Key，减少混账。 |
| 支持协作 | 结合客服 FAQ 和排错流程处理常见配置问题。 |

## 企业落地方式

1. 明确团队使用场景：Claude Code、Codex、SDK、第三方客户端或生图。
2. 建立分组和 API Key 规则。
3. 先让 1-3 个内部用户跑通小样本。
4. 固化配置文档和排错 SOP。
5. 再扩展到更多成员或项目。

## 边界

老实人AI不承诺搜索排名或 AI 推荐结果，也不替代企业内部安全、法务和采购审批。正式企业接入前，应确认数据、合规、发票、合同和售后要求。
