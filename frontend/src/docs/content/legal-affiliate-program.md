# 联盟计划规则

发布日期：2026-07-30

本规则适用于老实人AI联盟计划。联盟计划只有在控制台明确显示“已开放”后才开始生效；关闭或开放前检查期间，不发放奖励、不产生佣金，也不接受合伙人申请。正式开放前已经发生的注册、购买或消费，不追溯补发奖励；经平台核验的历史真实付费消费可以只用于合伙人申请资格。

本规则是《服务条款》的组成部分。如页面简要说明与本规则不一致，以本规则、实际绑定快照和平台结算记录为准。

## 1. 重要概念

- **⚡平台额度**：仅用于老实人AI平台内消费的虚拟额度，不能提现、转账或兑换现金。
- **现金佣金**：合伙人因直属客户的符合条件消费获得的可提现佣金。
- **首次实付**：被邀请账号在计划正式开放后，首次被平台确认为符合联盟条件的真实付费购买。具体以订单、卡密核销、月卡开通和联盟结算记录为准。
- **确认消费**：付费额度已经被真实调用消耗，并通过平台计费、退款和风险校验的消费。平台内部 1 个计费单位按 ¥1 计算，不进行美元兑人民币换算。
- **直属关系**：新账号首次注册时通过有效邀请链接形成的直接邀请关系。每个账号只能绑定一个直属邀请人，绑定后不因邀请人或被邀请人升级而改变。

## 2. 普通用户邀请

计划开放后，普通用户可以分享自己的邀请链接：

1. 新用户通过链接完成首次注册并形成有效直属关系。
2. 被邀请人完成首次实付后，邀请人与被邀请人各获得该笔符合条件金额 **5% 的 ⚡平台额度**。
3. 两份 5% 奖励在符合条件的首次实付确认后入账；页面和账单可能存在短暂刷新延迟。
4. 普通邀请奖励只计算一次，不因后续充值、月卡续费或消费重复发放。
5. 计划不再提供“满额另送固定 5 元”奖励。

使用邮箱密码、Gmail 或其他平台支持的登录方式，不影响有效邀请链接的绑定；但同一自然人或同一实际控制主体不得通过多个账号自邀自领。

## 3. 申请成为合伙人

成为合伙人**不需要缴纳加盟费或保证金**。申请人满足以下任一路线后可以提交申请，最终以平台审核结果为准：

- **路线 A：直属团队**

  至少 5 名有效直属用户；每名用户确认消费不少于 ¥20；达到单人门槛的有效直属用户确认消费合计不少于 ¥1,000。
- **路线 B：本人消费**

  申请人本人的确认消费不少于 ¥500，不要求邀请用户。

路线 A 只统计确认消费达到单人门槛的直属用户；路线 B 只统计申请人本人。系统会统计计划开放后的真实记录，并可将上线时已核验的历史真实付费消费计入资格；退款、撤销、异常交易和被冲正的消费不计入或会从进度中扣除。历史记录只影响申请资格，不追溯产生奖励或佣金。

达到门槛只代表可以申请，不代表自动成为合伙人。平台会结合资料完整性、推广方式、账号关联、支付风险、违规记录和服务能力进行审核。

## 4. 合伙人奖励池

合伙人审核通过后，每位直属客户的符合条件确认消费，最多产生该笔消费金额 **10% 的固定奖励池**。奖励池由两部分组成：

- 给直属客户的 **⚡平台额度返利**；
- 给合伙人的 **现金佣金**。

两部分之和始终为 10%，不会叠加为 10% + 10%。

合伙人默认链接按“客户 5% + 合伙人 5%”分配。合伙人可以按 1% 步进，将客户返利设置为 0% 至 10%；合伙人现金佣金自动等于 10% 减去客户返利。

每名客户绑定时会记录当时链接的分配比例。之后修改链接比例，只影响修改后新绑定的客户，不改变已经绑定客户的比例。

## 5. 升级前后的直属关系

- 普通用户升级为合伙人后，其原来邀请的直属用户仍然归属于本人。
- 升级前已经购买但尚未消费的余额，不因邀请人升级而自动变成可分润额度。
- 从合伙人审核通过时刻起，原直属用户**新购买的符合条件付费额度**在实际消耗后，按“客户 0% + 合伙人 10%”结算；原直属用户不会因为邀请人升级而自动获得长期返利。
- 合伙人通过合伙人链接新邀请的用户，按该用户绑定时的链接比例分配 10% 奖励池。

成为合伙人不会解除本人原有的上级绑定。合伙人自己的消费不给自己产生佣金；如果本人原来已绑定上级，其符合条件的本人消费仍可能按原绑定给直属上级结算。

## 6. 只结算一层直属关系

联盟计划只按直属关系结算，不计算间接下级：

- A 直接邀请 B，A 只可能从 B 本人的符合条件消费获得奖励。
- B 成为合伙人并直接邀请 C 后，C 的符合条件消费由 B 获得对应佣金，A 不从 C 的消费获得佣金。
- 任何一笔消费最多对应一个直属合伙人奖励池，不重复结算、不跨层抽成。

禁止自我邀请、使用小号互刷、共享实际控制账号、虚构交易、批量注册、循环支付、诱导性宣传或其他套取奖励的行为。

## 7. 佣金入账、提现和转额度

- 符合条件的确认消费完成后，合伙人佣金按当前结算状态入账；系统展示可能存在短暂刷新延迟。
- 合伙人可以随时提交提现申请。当前最低提现金额为 ¥100，并且必须先完成支付宝收款资料审核。
- 提交支付宝实名、账号、联系电话或收款码前，应阅读并单独同意[《合伙人收款资料隐私告知》](/legal/affiliate-payment-privacy)；拒绝提供不影响普通账号使用基础服务，但无法完成支付宝提现。
- 同一时间只允许一笔提现处于“处理中”。预计处理时限为提交后 24 小时内，时间均按北京时间计算。
- 到账时间还可能受收款账号状态、支付渠道、节假日、资料错误和风险复核影响。
- 可提现佣金可以按 **1:1.2** 转为 ⚡平台额度，例如 ¥10 佣金转为 ⚡12。转换完成后不可撤销，也不能再提现。
- 税费、代扣代缴和必要凭证按照适用法律法规及平台届时通知处理。

## 8. 退款、冲正和风险处理

如关联订单退款、支付撤销、消费被判定无效、系统重复计费、账号互刷、欺诈、异常关联或其他不应产生奖励的情形，平台可以：

- 撤销或扣回对应的 ⚡平台额度和现金佣金；
- 暂停提现、转换、邀请链接或合伙人权限；
- 要求补充资料并进行人工复核；
- 对已经提交但尚未打款的提现暂停处理；
- 对严重或重复违规终止合伙人资格，并保留必要的审计记录。

风险复核结束后，平台会根据核验结果释放、调整或扣回相关金额。对同一事件的冲正只执行一次，避免重复扣回。

## 9. 推广要求

分享邀请链接时，应当真实、清楚地介绍服务和奖励条件，不得：

- 承诺固定收益、保本回报、投资收益或“拉人即可赚钱”；
- 要求他人缴费、囤货、充值或购买资格后才能加入；
- 以发展间接下级数量或间接团队业绩作为收益依据；
- 冒充老实人AI员工、官方代理或获得未公示的授权；
- 发送垃圾信息、骚扰推广，或违反平台、支付渠道及适用法律。

平台可以要求合伙人修改或停止不当宣传。

## 10. 规则更新与联系

平台可以根据产品、成本、支付渠道、风险情况和适用规则调整联盟计划。对已经形成的直属绑定和链接比例快照，按照本规则明确的快照原则处理；其他调整会通过官网、控制台、公告或站内通知发布。

如对邀请绑定、奖励记录、消费冲正、资料审核或提现有疑问，请通过官网或控制台的官方客服渠道联系我们。
