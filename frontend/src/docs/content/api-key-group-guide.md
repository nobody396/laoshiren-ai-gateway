# API Key 与分组选择指南

老实人AI里最容易混淆的是 API Key、订单号、兑换码和分组。客户端里真正要填的是 API Key。

## 四个概念

| 名称 | 用途 | 能不能填进客户端 |
| --- | --- | --- |
| API Key | 客户端鉴权，发起模型调用 | 可以 |
| 订单号 | 查询支付或售后记录 | 不可以 |
| 兑换码 | 兑换余额或权益 | 不可以 |
| 分组 | 决定模型、协议、倍率、限制和路由 | 不能直接填，但必须选对 |

## 分组怎么选

- Claude Code：选择支持 Claude Code/Anthropic 协议的分组。
- Codex：选择支持 Codex/OpenAI 协议的分组。
- OpenAI SDK：选择支持 OpenAI 兼容协议的分组。
- 第三方客户端：选择明确支持第三方调用的分组。
- 生图：选择已开放的生图分组。

## 分组选错会怎样

- 模型列表不显示。
- 模型名看起来对，但调用失败。
- 返回 401、403、404、429 或协议错误。
- 使用记录里显示走了错误的 Key 或错误的分组。

## 建议做法

为不同项目和工具创建不同 API Key。比如 Claude Code 一个 Key，Codex 一个 Key，第三方客户端一个 Key。这样后续排查用量、成本和错误会更清楚。

不要在群聊、论坛或工单里发送完整 API Key。如果已经公开发送，立即删除旧 Key 并重新生成。
