# 常见 API 报错排查

这页用于快速判断老实人AI调用中的常见错误码。

## 错误码地图

| 错误 | 常见含义 | 优先检查 |
| --- | --- | --- |
| 401 | 鉴权失败 | API Key 是否完整、是否填错位置 |
| 403 | 权限或来源被拒绝 | 分组、接口、CORS、账号状态 |
| 404 | 路径或模型不存在 | Base URL、模型名、客户端协议 |
| 429 | 限流或额度不足 | 余额、分组限制、并发、请求频率 |
| 502 | 上游或网关临时失败 | 上游账号、网络、重试情况 |
| 503 | 上游不可用或临时拥塞 | 模型路由、上游状态、是否已故障转移 |
| 超时 | 链路或模型响应慢 | 网络、代理、模型耗时、长连接 |

## 标准排查顺序

1. 先确认入口工具：Claude Code、Codex、SDK、第三方客户端或生图。
2. 再确认 Base URL、API Key、分组、模型名。
3. 看老实人AI使用记录里是否有请求。
4. 有请求时看错误码、模型、分组、耗时和上游状态。
5. 无请求时先查本地配置、环境变量、代理和客户端版本。

## 发给客服的信息

可以提供：

- 使用入口
- 报错时间
- 模型名
- 分组名
- 打码截图
- Request ID 或使用记录截图

不要提供：

- 完整 API Key
- 完整邮箱
- 订单原图
- 生产代码或客户隐私文件
