# Customer tiers change compensation size, not eligibility

Customer Tier belongs to the user account rather than an API key, order, or subscription plan, so every access path under one account shares the same service-recovery classification. The initial tiers use rolling 90-day Verified Paid Value: Standard is below CNY 250, Priority is CNY 250 through CNY 999.99, and Strategic is CNY 1,000 or more. Classification is recalculated daily from rolling verified paid value and verified paid consumption, with lifetime paid value protecting loyal customers; upgrades apply immediately and downgrades have a 30-day grace period. Consumption speed is not a qualification input. A Customer Tier Snapshot is frozen at the start of each Customer Impact Window. Tier affects only the Customer Tier Multiplier and the per-user, per-incident maximum benefit: Standard uses 1.0x with a CNY 10 equivalent cap, Priority uses 1.25x with a CNY 50 equivalent cap, and Strategic uses 1.5x with a CNY 200 equivalent cap. Every affected customer remains subject to the same Compensation Policy eligibility rules. Time-bounded audited overrides may change future classifications but cannot modify an existing incident snapshot.
