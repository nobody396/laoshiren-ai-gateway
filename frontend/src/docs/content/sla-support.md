# 服务状态与支持说明

这页用于判断老实人AI主站、API 和模型接入链路是否正常。

## 快速入口

- 主站：<https://laoshirenai.com>
- API 健康检查：<https://api.laoshirenai.com/health>
- 文档中心：<https://laoshirenai.com/docs>
- 模型检测报告：首页“模型检测”区域

## 判断顺序

1. 主站是否能打开。
2. API 健康检查是否返回正常。
3. 使用记录里是否出现请求。
4. 错误集中在单个模型、单个分组、单个 Key，还是全局。
5. 是否有网络、代理、客户端版本或旧配置问题。

## 支持边界

老实人AI可以协助排查 Base URL、API Key、分组、模型、使用记录、常见报错和平台链路问题。第三方客户端自身 bug、用户本地网络、企业内网代理和上游模型策略变化，需要结合实际情况判断。

## 提交问题时请提供

- 使用入口
- 发生时间
- 模型名
- 错误码或打码截图
- Request ID 或使用记录截图

不要发送完整 API Key、完整邮箱、订单原图或客户隐私文件。
