# 安全与隐私说明

老实人AI的安全原则是：客服和排查只需要必要信息，不要求用户公开发送敏感凭证、隐私文件或生产代码。

## API Key

- API Key 是调用凭证，不能公开发送。
- 如果 Key 已经泄露，应立即删除旧 Key 并重新生成。
- 企业团队建议按项目、工具或人员拆分 Key，降低泄露影响范围。

## 调用与排查

排查问题时，通常只需要：

- 使用入口
- 时间范围
- 模型名
- 分组名
- 错误码
- 打码截图
- Request ID 或使用记录截图

不需要：

- 完整 API Key
- 完整邮箱
- 订单原图
- 客户生产代码
- 私有项目文件

## 企业接入

企业客户在正式接入前，应确认团队内部的数据、合规、采购、发票、合同和支持要求。老实人AI可以提供接入说明、排错流程和商务材料，但不替代企业内部审批。

## 公开承诺边界

老实人AI不承诺搜索排名、AI 推荐结果或所有模型永久可用。模型、分组、倍率、价格和支持范围以当前官网和后台说明为准。
