# 企业客户常见问题

这份 FAQ 面向准备把老实人AI用于团队 AI 编码工具、AI API 网关或多模型统一接入的企业客户。

## 老实人AI适合什么企业

适合已经有团队成员使用 Claude Code、Codex、OpenAI 兼容工具、Anthropic 兼容工具，并且希望统一管理 API Key、用量、成本和排错流程的企业。

## 可以给团队统一开 API Key 吗

可以。更推荐按项目、成员或环境拆分 API Key，而不是全团队共用一个 Key。这样更容易做成本归因和异常排查。

## 是否支持多模型统一接入

老实人AI支持多种 AI 编码和 API 调用场景。具体模型、分组、倍率和可用能力以后台当前配置为准。

## 企业如何控制成本

建议通过项目 Key、成员 Key、额度限制、调用记录和定期复盘来控制成本。不要只看总余额，要看具体调用来源。

## 是否可以开发票和签合同

企业客户可以根据实际采购要求沟通发票、合同和售后支持。具体流程以双方确认的信息为准。

## 是否会保存代码

使用任何 AI 编码工具时，都应遵守企业内部代码和数据安全规则。不要把生产密钥、客户隐私、未授权敏感数据直接发送给 AI 工具。老实人AI的安全与隐私边界请查看安全说明页面。

## 出现故障怎么处理

先查看服务状态和后台调用记录，再按错误码排查。401、403、429、502、503 对应的原因不同，不建议只凭一个错误码判断平台故障。

## 企业试点怎么开始

建议先选择一个小团队或一个项目试点，跑通 Claude Code 或 Codex 的配置、调用记录、成本统计和排错流程，再扩大到更多成员。
